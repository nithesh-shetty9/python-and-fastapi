## 1. Introduction to Python

Python is a high-level, general-purpose, dynamically typed programming language.

It is widely used in:
- Backend development
- Artificial Intelligence
- Machine Learning
- Data Science
- Automation

## 2. Printing Output

Python uses `print()` to display output.

```python
print("Hello World")
```

JavaScript equivalent:

```javascript
console.log("Hello World");
```

## 3. Variables

Python does not require explicit type declarations.

```python
a = 10
b = 20

name = "Nithesh"
price = 99.5
is_active = True
```

Python determines the type dynamically.
